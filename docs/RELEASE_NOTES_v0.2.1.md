# DraftAI 0.2.1 - Corrección de interfaz y Pro de pruebas

Interfaz corregida a partir de Contexto/Mockup/mockup_screens y mockup.css: tarjetas de carpetas neutras, color solo en el icono y muestra HEX pulsable; lápiz para renombrar. Se elimina el nivel adicional de categorías de los formularios y pantallas, manteniendo los datos antiguos compatibles.

En un apunte, Nuevo, Editar, IA central destacada, Exportar y Más vuelven a estar visibles. Lectura tiene acceso directo y ajuste de tamaño del texto. El editor usa las dos filas del mockup: B/I/H1/lista/fórmula/deshacer/rehacer y Dictar/Cámara/Mejorar/Tipos. Insertar imágenes/archivos queda como acción discreta de la cabecera, conservando la posición del cursor. Doble toque amplía la imagen y otro doble toque la ajusta; mantiene gesto de pinza y galería deslizable.

Colores neutros compartidos en modo claro/oscuro, formularios y menús. Biblioteca opcional de 120 apuntes en 8 carpetas, 24 temas, fechas de ocho meses, imágenes intercaladas y PDF. Instalación nueva vacía. Si ya cargaste los ejemplos anteriores, elimínalos desde Perfil → Biblioteca de prueba y carga los nuevos; tus notas propias se conservan.

Pro de pruebas: OpenAI gpt-5-nano-2025-08-07 para texto e imágenes; Gratis continúa con Groq openai/gpt-oss-20b. Autorización Pro en el servidor por dispositivo; el plan visual sigue siendo una simulación sin pagos. Se conservan límites persistentes, validación, moderación de entrada/salida y rol fijo de transformación de apuntes, sin chat libre ni herramientas externas. Claves cifradas fuera de Git y APK.

Se omiten las pruebas automatizadas, capturas y emulador a petición del propietario. Verificación limitada al analizador estático, compilación, firma, versión y auditoría de claves del APK; conexión pequeña real al proveedor Pro. No se afirma equivalencia visual verificada en un teléfono ni una prueba funcional completa.

Android 8.0/API 26 mínimo, target 36. Flutter 3.47.2, Dart 3.13.2, Java 17. Versión 0.2.1+4. iOS no validado. Google y pagos reales pendientes. Servidor y túnel del propietario deben seguir activos para usar IA remota.
