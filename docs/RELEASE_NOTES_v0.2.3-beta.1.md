# DraftAI 0.2.3 Beta 1 · Android

Beta para pruebas: puede contener errores.

- Edición sin guardado automático; aviso para guardar o descartar al salir.
- Volver desde lectura regresa a la vista del apunte.
- Temas con fecha de última edición y selección individual para la IA.
- El filtro por fechas respeta los apuntes y temas marcados.
- Google muestra un aviso y ofrece acceso local como usuario de prueba.
- Estado de IA comprobado con el servidor; sin código no se anuncia conexión.

Android 8.0 o superior. Instala sobre tu versión anterior para conservar las notas. La IA requiere conectar el servidor de pruebas; Google y pagos siguen simulados.
