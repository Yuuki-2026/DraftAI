# Revisión de los HTML del mockup

Se leyeron los 153 archivos HTML bajo Contexto/Mockup (1105597 bytes), incluidos HTML canónicos, variantes de invitado y pantallas originales. Referencias sin modificar. Informe completo local en artifacts/022-all-html-inventory.json, fuera de Git.

Las indicaciones actuales del propietario prevalecen sobre ejemplos estáticos: carpetas como único nivel, IA remota real, Google/pagos simulados, sin porcentajes de certeza inventados ni indicadores locales de OCR inexistente.

| Grupo de referencia | Aplicación en 0.2.2 |
|---|---|
| destino-de-fotos, agregar-archivos, camara | Origen de archivos, vista del lote y elección IA/manual |
| dejalo-a-la-ia-procesando | Progreso de grupos, lectura/clasificación y cancelación real |
